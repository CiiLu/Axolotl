# 投影预览

**投影预览 (Schematic Preview)** 是建筑党的福音！

## 它能做什么？

直接打开 `.schem` / `.schematic` 建筑投影文件：

- 🏗️ 预览建筑成品的完整效果
- 🔍 查看每个方块的构成
- 📏 了解建筑尺寸和规模

## 典型用法

- **下建筑前先看效果**：下载别人的建筑投影，先预览再决定装不装
- **检查建筑细节**：放大看方块布局，学习大佬的建筑手法
- **规划改造方案**：在预览里研究建筑结构，改造不踩雷

## 使用方式

打开实验室 → 投影预览，加载投影文件即可查看。内置资源支持常见方块显示，开箱即用，无需额外配置。
