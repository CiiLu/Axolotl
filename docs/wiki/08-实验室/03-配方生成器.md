# 配方生成器

**配方生成器 (Recipe Generator)** 让你可视化地设计自定义合成配方，做整合包、搞自定义玩法必备！

## 它能做什么？

- 🔧 可视化设计合成配方（工作台、熔炉、切石机等）
- 📦 支持物品 ID、数量、位置自由配置
- ⬇️ 一键导出成**数据包**，直接塞进世界或服务器

## 典型用法

- **自定义玩法**：给整合包添加新配方，比如"用泥土合成钻石"（生存模式快乐加倍）
- **模组联动**：为模组物品设计合成路线
- **服务器定制**：调整服务器的合成表，平衡经济与玩法

## 使用方式

打开实验室 → 配方生成器：

1. 选择配方类型
2. 摆放配方格子（物品、数量、位置）
3. 预览成品与合成布局
4. 导出数据包，放进世界的 `datapacks` 文件夹即可生效

> 💡 导出时可以选择导出到当前实例，启动器直接帮你放进对应的数据包目录，开服即用！
