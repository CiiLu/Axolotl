# 渐变文字

**渐变文字 (Gradient Text)** 让你一键生成 Minecraft 渐变色文字，聊天、告示牌、物品名都能用！

## 它能做什么？

- 🌈 输入文字，自动生成渐变效果
- 🎨 自定义渐变色（起始色 → 结束色）
- 📋 一键复制，直接粘贴到游戏里使用

## 支持渐变颜色的地方

- 💬 **聊天**：发出去就是酷炫渐变色
- 📋 **告示牌**：服务器告示牌文案亮起来
- 🏷️ **自定义物品名**：数据包/命令场景下的物品显示名

## 使用方式

打开实验室 → 渐变文字：

1. 输入文字内容
2. 选择渐变起止颜色（支持多种预设配色）
3. 生成预览，满意后一键复制代码
4. 粘贴到游戏里，完成！
