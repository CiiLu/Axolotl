# 模组翻译

**模组翻译 (Mod Translation)** 是模组汉化的得力助手，帮模组作者和汉化组省下大把时间。

## 它能做什么？

- 🔍 针对**未汉化的模组**，提供完整的翻译工作流
- 📝 可视化编辑翻译条目，键值对照一目了然
- 📦 支持导出 / 导入翻译文件
- ⚙️ 翻译进度跟踪，还剩多少条目没翻，心里有数

## 谁适合用？

- **模组作者**：发布模组时快速生成多语言文件
- **汉化组**：批量翻译模组的标配工作流
- **普通玩家**：喜欢的模组没汉化？自己动手补上，顺便造福社区

## 使用方式

打开实验室 → 模组翻译：

1. 选择要翻译的模组（从已安装实例中选取）
2. 对照原文逐条翻译
3. 保存进度，随时继续
4. 导出翻译文件，放入模组目录生效

> 💡 翻译进度会本地保存，翻到一半关掉也不怕，下次接着翻~
