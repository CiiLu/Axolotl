# 安装与更新

## 下载安装

前往 [GitHub Releases](https://github.com/Mystic-Stars/Axolotl/releases/latest) 下载适合你系统的最新安装包：

| 系统平台 | 推荐下载文件 |
|---|---|
| **Windows** (10/11 x64) | `.exe`（NSIS 安装程序） |
| **macOS** | 通用 `.dmg` 镜像（Intel / Apple Silicon 通用） |
| **Linux** (x64) | `.AppImage` / `.deb` / `.rpm` 均可 |

## Linux 包管理器快捷安装

**Arch Linux (AUR)：**

```bash
# 源码构建版
yay -S axolotl-launcher

# 预编译二进制版
yay -S axolotl-launcher-bin
```

**Debian / Ubuntu (APT)：**

```bash
curl -fsSL https://ppa.axlmc.org/setup.sh | sudo bash
sudo apt install axolotl-launcher
```

## 自动更新

已安装的用户不用操心更新！Axolotl 内置 **Tauri 签名校验机制**，新版本发布后会在后台自动完成下载与安装，无需手动折腾。(・ω・)ノ

升级启动器版本是完全无损的：你的实例、模组、存档、设置都会原样保留，放心大胆更新。
