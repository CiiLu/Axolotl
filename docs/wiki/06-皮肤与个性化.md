# 皮肤与个性化

看腻了默认界面？Axolotl 的个性化设置让你随心打扮。(・ω・)ノ

## 离线皮肤

离线账户也能拥有专属皮肤！

1. 打开 **皮肤 (Skins)** 页面
2. 上传你的皮肤文件（PNG 格式）
3. 启动器自动为离线账户应用皮肤
4. 进游戏就能看到效果

> 💡 皮肤文件可以自己在网上找资源，或者用皮肤站的生成器做一顶属于自己的皮肤。

## 主题色调

在设置中调整启动器的主题配色，换一套你喜欢的颜色，界面心情都焕然一新。

## 背景图片

自定义启动器的背景图片，放一张你喜欢的截图或壁纸，每次打开启动器都是好心情。

## 多语言

内置多语言支持（通过社区翻译协作维护），在设置里一键切换界面语言，妈妈再也不用担心我看不懂英文了。
