# 多人游戏

**多人游戏 (Multiplayer)** 页面帮你集中管理所有服务器，开黑更方便！

## 管理服务器

- **添加服务器**：填入服务器地址（IP 或域名）和名称，保存即可
- **编辑 / 删除**：随时维护你的服务器列表
- **排序整理**：常用服务器置顶，一目了然

## 在线状态探测

服务器列表会显示每个服务器的在线状态：

- 服务器是否在线、多少人玩，一眼看到
- 找服不再靠猜，关服了不用白等

## 点击即连

点击服务器即可启动对应实例直接进入：

- 启动器会自动选择/启动合适的实例
- 支持一键切换实例，PVP 服、生存服各配一个实例，互不干扰

## 好友开黑

服务器列表加上[实例隔离](../04-游戏库与实例/01-什么是实例.md)的组合拳，每个服务器都有独立的模组环境，再也不用反复装卸模组了~
