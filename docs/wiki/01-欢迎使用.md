## 这是什么？

Axolotl Launcher 是一款**免费、开源、跨平台**的 Minecraft Java 版第三方启动器。它基于 [Modrinth App](https://github.com/modrinth/code) 构建，移除了商业化模块，专注于提供**纯净、无广告**的桌面启动体验。

简单来说：**一个启动器，搞定你所有 Minecraft 需求。**

## 核心特性

- **真·跨平台**：原生支持 Windows、macOS（Intel 与 Apple Silicon 通吃）以及主流 Linux 发行版，告别繁琐的环境配置。
- **现代化内容生态**：内置 Modrinth 与 CurseForge 双平台内容中心，模组、整合包、资源包、光影一站式浏览、安装、升级。
- **高度定制化**：主题色调、背景图片、离线皮肤……核心功能与视觉展现都由你自由支配。
- **All in One 实验室**：内置"实验室"功能，种子地图、投影预览、配方生成器等实用工具一应俱全。
