# 实验室

**实验室 (Lab)** 是 Axolotl 的独门绝活——内置在启动器里的实用工具箱！

| 页面 | 内容 |
|---|---|
| [种子地图](08-实验室/01-种子地图.md) | 输入种子预览地形，找村庄找要塞 |
| [投影预览](08-实验室/02-投影预览.md) | 打开建筑投影文件，预览成品效果 |
| [配方生成器](08-实验室/03-配方生成器.md) | 可视化设计合成配方，导出数据包 |
| [渐变文字](08-实验室/04-渐变文字.md) | 一键生成 Minecraft 渐变色文字 |
| [模组翻译](08-实验室/05-模组翻译.md) | 未汉化模组的翻译工作流 |

从启动器侧边栏进入实验室，五个工具随便玩~ (≧▽≦)
