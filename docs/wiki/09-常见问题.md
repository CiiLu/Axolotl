# 常见问题 (FAQ)

**Q：Axolotl 是收费的吗？会放广告吗？**
A：完全免费、开源（GPL-3.0），无广告。项目移除了商业化模块，专注纯净体验。

**Q：和 Axolotl Client 是什么关系？**
A：没有任何关系！我们是完全独立的项目，只是名字撞了（我们是美西螈启动器）。

**Q：能玩离线模式吗？**
A：可以。创建离线账户即可离线游玩，但离线模式无法进入开启正版验证的服务器。

**Q：支持哪些模组加载器？**
A：Fabric、Forge、Quilt、NeoForge 等主流加载器都支持，创建实例时按需选择。

**Q：怎么更新启动器？**
A：完全自动。启动器后台自动检测新版本，通过签名校验完成更新，无需手动操作。

**Q：我的游戏存档/模组会丢吗？**
A：实例之间完全隔离，卸载启动器也不会动你的存档。升级启动器版本更是无损的，放心大胆更新。

**Q：安装模组后游戏启动崩溃怎么办？**
A：先看实例的**日志页**，找到报错原因（常见的是模组冲突或依赖缺失）。也可以禁用可疑模组逐个排查。实在搞不定就去 [GitHub Issues](https://github.com/Mystic-Stars/Axolotl/issues) 求助，记得附上日志。

**Q：可以在多个设备上用吗？**
A：当然！启动器支持 Windows / macOS / Linux，每个平台都有对应安装包，实例文件夹也可以自己备份迁移。

**Q：遇到 Bug 怎么报？**
A：去 [GitHub Issues](https://github.com/Mystic-Stars/Axolotl/issues) 提交，附上实例日志和复现步骤，开发者会尽快处理。
