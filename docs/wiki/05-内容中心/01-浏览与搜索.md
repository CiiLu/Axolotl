# 浏览与搜索

**浏览 (Browse)** 页面是 Axolotl 的内容中心，Modrinth 与 CurseForge 两大平台的内容在这里合流。

## 内容类型

| 类型 | 说明 |
|---|---|
| 🔧 **模组 (Mods)** | 为游戏加功能、改玩法 |
| 📦 **整合包 (Modpacks)** | 一键安装整套模组体验 |
| 🎨 **资源包 (Resource Packs)** | 换皮肤、换界面、换音效 |
| ☀️ **光影 (Shader Packs)** | 让画面美到窒息 |

## 搜索

顶部搜索框支持关键词搜索，输入模组名、作者名都能搜。搜索结果会合并展示两个平台的命中项。

## 筛选

- **平台**：Modrinth / CurseForge / 全部
- **分类**：按内容类型、题材筛选
- **加载器**：Fabric / Forge / Quilt 等
