# 安装与升级

## 安装内容到实例

在项目页点击安装，三步完成：

1. 选择目标**实例**
2. 选择**版本**（启动器自动匹配兼容的游戏版本，一般不用手动选）
3. 点击安装，等待下载完成

## 安装到哪个实例？

支持两种选择：

- 安装到**已有实例**：在实例列表里选一个
- 创建**新实例**：如果还没合适的实例，安装时直接新建一个

## 一键升级

内容作者发布了新版本？不用去网站手动下载：

- 在实例的**模组页**查看可升级的模组
- 点击**升级**按钮，启动器自动完成下载与替换

升级是"差分"进行的，只更新有变化的部分，又快又稳。

## 依赖自动处理

很多模组依赖前置库（比如 Fabric API），启动器会自动检测并处理依赖：

- 缺依赖时会明确提示
- 安装时会自动带上必要的依赖

手动管理依赖的痛苦，在这里彻底结束。
