# 项目详情页

点进任何一个项目（模组/整合包/资源包/光影），会看到完整的项目详情：

## 描述 (Description)

项目作者的详细介绍：

- 项目简介、功能特性
- 图片展示
- 使用说明

## 版本 (Versions)

项目发布过的所有版本列表：

- 每个版本对应的游戏版本、加载器一目了然
- 直接从这里选择版本安装
- 查看版本发布日期与更新说明

## 更新日志 (Changelog)

作者的版本更新记录：

- 看看这次更新改了啥、修了啥 Bug
- 决定要不要升级的参考依据

## 图库 (Gallery)

项目的截图与图片展示，好不好看，看了再决定。

## 双平台支持

- Modrinth 项目有专门的 **CurseForge 视图**（如果该项目在 CurseForge 也有发布）
- 平台之间的切换无缝进行，信息互通
