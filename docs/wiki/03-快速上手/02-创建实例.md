# 创建实例

登录账户之后，就可以创建你的第一个游戏实例啦！

## 点击创建

在启动器首页点击 **创建 (Create)**，进入创建流程。

## 选择游戏版本

你可以选择：

- **原版 (Vanilla)**：官方纯净版，任意版本都有
- **模组加载器版本**：Fabric、Forge、Quilt、NeoForge 等主流加载器，按需选择

## 或者直接装整合包

不想从零折腾？可以直接搜索并安装现成的**整合包**，一键开玩。整合包自带整套模组配置，适合想省事的玩家。

## 从文件导入

朋友分享给你的整合包文件（`.mrpack` 或 zip 格式），通过导入功能直接拖进来就能创建实例。

## 启动游戏

创建完成后，实例会出现在**游戏库 (Library)** 页面。点击实例上的 **启动** 按钮，等待下载完成，游戏就开跑啦！

第一次启动会下载对应版本的游戏文件，耗时取决于网络速度，之后启动就快多啦。
