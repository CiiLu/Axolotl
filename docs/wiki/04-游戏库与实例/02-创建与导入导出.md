# 创建与导入导出

## 创建实例

在首页点击 **创建 (Create)**：

1. 选择游戏版本（原版或带 Fabric / Forge / Quilt / NeoForge 加载器）
2. 或直接搜索安装**整合包**，一键创建
3. 创建后可自定义实例名称、图标等

## 导入整合包

支持两种导入方式：

- **`.mrpack` 文件**：Modrinth 整合包标准格式
- **zip 压缩包**：常见整合包分发格式

导入方式：把文件直接拖进启动器窗口，或通过导入按钮选择文件。

## 导出与分享

想把自己的实例分享给朋友？导出功能帮你打包：

1. 在实例详情页选择导出
2. 启动器会整理实例内容，打包成整合包文件
3. 把文件发给朋友，对方导入即可获得同款体验

导出时可以选择包含/排除哪些内容（比如要不要带上存档），灵活控制分享范围。
