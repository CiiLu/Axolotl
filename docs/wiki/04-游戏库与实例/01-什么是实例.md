# 什么是实例

**实例 (Instance)** 是 Axolotl 的核心概念，理解它，你就掌握了启动器的灵魂。

## 一句话解释

实例就是一套**独立的游戏环境**：独立的游戏版本、独立的模组、独立的世界和设置。

## 为什么要用实例？

- **互不干扰**：给不同的整合包、不同的服务器分别创建实例，模组冲突？不存在的，各玩各的
- **完美隔离**：删掉一个实例不会影响其他实例，游戏本体也不会被污染
- **自由组合**：同一个游戏版本可以装出"纯净版""生存整合版""PVP 特化版"多个实例，想玩哪个点哪个

## 游戏库页面

**游戏库 (Library)** 页面是实例的总入口，提供多种视图：

| 视图 | 说明 |
|---|---|
| **概览 (Overview)** | 所有实例的汇总视图，从这里启动游戏 |
| **官方 (Official)** | 按游戏版本创建的原版实例 |
| **整合包 (Modpacks)** | 从整合包创建的实例 |
| **已下载 (Downloaded)** | 已安装内容的汇总 |
| **服务器 (Servers)** | 服务器快捷入口，见[多人游戏](../07-多人游戏.md) |
| **自定义 (Custom)** | 手动配置的实例 |

## 实例从哪来？

- **创建**：选版本/加载器新建，见[创建实例](../03-快速上手/02-创建实例.md)
- **整合包**：一键安装现成整合包
- **导入**：从 `.mrpack` / zip 文件导入别人分享的实例

创建好之后，点进任意实例就能看到它的[详情页](03-实例详情页.md)啦！
