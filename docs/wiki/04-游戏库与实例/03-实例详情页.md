# 实例详情页

点进任意实例，你会看到功能齐全的详情页，通过顶部标签页切换：

## 概览 (Overview)

实例的"主驾驶舱"：

- 实例基本信息（名称、图标、版本）
- **启动 / 停止**按钮
- 版本信息一目了然

## 模组 (Mods)

管理已安装的模组：

- 启用 / 禁用单个模组
- **一键升级**到新版本
- 卸载不需要的模组
- 查看模组依赖关系，缺依赖一眼看出

## 文件 (Files)

浏览实例的完整文件结构：

- 资源包、光影包、配置文件都能在这里找到
- 相当于可视化的 `.minecraft` 文件夹

## 日志 (Logs)

实时查看游戏日志：

- 启动报错、崩溃排查的神器
- 报 Bug 给开发者时，从这里复制日志最方便

## 世界 (Worlds)

管理实例的存档：

- 查看所有世界存档
- 内置**世界编辑器**，可以直接调整存档内容

## 截图 (Screenshots)

游戏内按 F2 截的图都会出现在这里，回顾你的高光时刻~
