# 支持与贡献

Axolotl Launcher 的进步离不开社区的支持！(｡•̀ᴗ-)✧

## 反馈 Bug / 提需求

遇到 Bug 或有新的功能点子，欢迎提交 Issue：

- **地址**：[GitHub Issues](https://github.com/Mystic-Stars/Axolotl/issues)
- **报 Bug 建议附上**：实例日志（实例详情 → 日志页）、复现步骤、系统环境

## 参与开发

想从玩家变成开发者？欢迎！

- 阅读 [CONTRIBUTING.md](https://github.com/Mystic-Stars/Axolotl/blob/main/CONTRIBUTING.md) 了解本地开发环境搭建与打包发布规范
- 项目是 Rust (Tauri) + Vue 的 monorepo，提交 PR 前记得看看贡献指南

## 帮忙翻译

项目使用 **Crowdin** 进行社区翻译协作：

- 把 Axolotl 翻译成更多语言，让它走向全世界
- 翻译工作流细节见 [06-皮肤与个性化](06-皮肤与个性化.md) 的多语言章节
